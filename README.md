# VERO - Sistema de Autenticação

Sistema de autenticação desenvolvido com HTML, CSS e JavaScript.

O projeto simula um fluxo completo de cadastro, login, gerenciamento de sessão e acesso a uma área autenticada.

## Funcionalidades

- Cadastro de usuários
- Login com validação de credenciais
- Controle de sessão
- Dashboard personalizado
- Logout
- Proteção da área autenticada
- Redirecionamento de usuários não autenticados
- Exibição dos dados do usuário atualmente conectado
- Interface responsiva
